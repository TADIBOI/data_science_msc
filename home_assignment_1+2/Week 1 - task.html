    Assignment 1: Data Workflow

    Repeat the workflow from Week1_Data_Workflow_and_Acquisition.ipynb on a different dataset.

    Dataset rules

    • CSV or Excel, ideally ≥ 500 rows, ≥ 5 columns
    • Include: 1 date-like column, 2 numeric columns, 1 categorical/text column
    • Must have at least one quality issue (missing, duplicates, mixed types, currency symbols, messy dates, etc.)

    Project structure (required)

    your_project/
  data/
    raw/
    interim/
    processed/
  configs/
  reports/
    Rule: Put originals in data/raw and never overwrite them. Save intermediate work to data/interim and final analysis-ready data to data/processed.

    Tasks

    1. Setup paths: create folders with Path(...).mkdir(...) and a small configs/config.json.
    2. Load: read the raw file from data/raw using pandas.
    3. Check (show outputs): shape, head, info, missing summary, duplicates count.
    4. Clean: write a function clean_mydata(df) and do at least 4: rename columns, parse dates, numeric conversion, remove symbols/commas, handle missing, drop duplicates, create 1 derived column, sort + reset index.
    5. Validate: add ≥ 3 rules (e.g., non-negative values, required IDs not null, dates parsed, no duplicate keys). Use assert or clearly log-and-fix.
    6. Save:
      • data/interim/<name>_interim.csv
      • data/processed/<name>_processed.csv
      • One summary table to reports/summary_table.csv

    Submit

    • Notebook: Assignment1_DataWorkflow_YourName.ipynb
    • Folders/files: configs/config.json, raw + interim + processed outputs, reports/summary_table.csv
